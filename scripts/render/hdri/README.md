# The render scripts' room

`lythwood_lounge_2k.hdr` is the room every rendered part reflects (the tape echo, Corona,
Patina, the pedals, Orbit): Lythwood Lounge by Poly Haven, 2K, from
https://polyhaven.com/a/lythwood_lounge. Poly Haven releases it under CC0 (public
domain), so it is bundled here unchanged; the scripts find it without any setting
(`scripts/render/render_config.py`; `NORTHLIGHT_HDRI` points them at another file).

It is only for rendering: nothing in the app loads it, and it is not copied with the
assets.
