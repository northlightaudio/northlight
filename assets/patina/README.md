# Patina's face

The images Patina's card draws its rack-unit face with (screens/plugins.md 7.2a).
All three were generated for Northlight with FLUX.1 [dev] (ComfyUI, GGUF Q6_K) and
colour-graded to the face; nothing in them comes from a photograph or another product.

| File | What it is |
|---|---|
| `panel-aged.jpg` | Hammertone enamel on steel after decades of use: the panel |
| `nameplate.jpg` | A blank, yellowed enamel nameplate with a screw at each end, drawn nine-sliced so the screws keep their shape |
| `lamp.jpg` | A pilot lamp's red jewel in a worn chrome bezel |

The card falls back to flat token colours when a file is missing (the tests run that
way), so the face never depends on them to work.
