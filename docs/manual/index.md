This manual explains how to use Northlight, from installing it and setting up audio to
recording, mixing and exporting a song. It describes the version of Northlight it was
published with.

New to recording music on a computer? Start with
[Getting started](getting-started/installing.md), which ends with a song made from
scratch. The other sections can be read in any order: look up what you need when you
need it.

## How the manual writes things

- **Bold** words are what you see on screen: a button, a menu item, a setting.
- Menu paths read left to right: **Preferences > Recording** means the Recording page
  of Preferences.
- Keys are written as they are labelled: Ctrl+S means hold Ctrl and press S. Every
  key can be changed in **Preferences > Shortcuts**, so the manual gives the
  default ones.

## Something missing or wrong?

The manual is written in the open, beside the code. If a page is unclear, out of date
or missing, [open an issue](https://github.com/northlightaudio/northlight/issues) or
edit the page: its source is in the `docs/manual` folder of the
[Northlight repository](https://github.com/northlightaudio/northlight).
